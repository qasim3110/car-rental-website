# Car Rental Website — حل الوظيفة

## محتويات المشروع

| الملف | الوظيفة |
|---|---|
| `home.html` | الصفحة الرئيسية، أسماء المجموعة، رابط النشر والملاحظات |
| `AboutUs.html` | معلومات مكتب التأجير والتواصل والفروع وأوقات الدوام |
| `Cars.html` | جدول من 6 سيارات، صورها، اختيار متعدد، تفاصيل jQuery، ونموذج الحجز |
| `style.css` | ملف التنسيق الموحد والمتجاوب |
| `myFunctions.js` | ملف JavaScript الوحيد للتحقق والحساب والتفاعل |
| `AI_Feature_Report.html` | تقرير مختصر عن ميزة «مستشار السيارة الذكي» |

## التشغيل

افتح `home.html` في المتصفح. تحتاج صفحة `Cars.html` إلى اتصال بالإنترنت لتحميل مكتبة jQuery من CDN.

## خطوات ما قبل التسليم

1. بيانات الطلاب الأربعة ورابط GitHub Pages موجودة في `home.html`.
2. أعد تسمية الملف المضغوط باسم أرقام الطلاب المشاركين وفق تعليمات المدرّس، ثم ارفعه إلى Moodle.

## الوظائف المنفذة

يستخدم المشروع XHTML 1.0 Strict مع إغلاق الوسوم الفارغة ووضع قيم السمات بين علامتي اقتباس. تم فحص الصفحات الأربع مقابل تعريف XHTML 1.0 Strict الرسمي. وللحفاظ على التوافق مع XHTML 1.0، تستخدم حقول التاريخ والهاتف والبريد حقولًا نصية ويتولى JavaScript التحقق منها.

يتحقق JavaScript برسائل واضحة من الاسم العربي، والرقم الوطني المؤلف من 11 خانة والذي يبدأ برمز محافظة من 01 إلى 14، وصحة التواريخ، وبادئات أرقام الهاتف 090 و093 و098 و099 لـ Syriatel، و094 و095 و096 لـ MTN Syria، وصحة البريد الإلكتروني. كما يمنع تاريخ نهاية يساوي أو يسبق تاريخ البداية، ويحسب مدة التأجير ومبلغ كل سيارة والمجموع النهائي مع خصم 10% عند تجاوز 7 أيام.

تظهر تفاصيل عدة سيارات أو تختفي باستخدام jQuery و`slideToggle` دون إعادة تحميل الصفحة، مع صورة ومواصفات كل سيارة. توجد صور السيارات الست في جذر المشروع وتستخدم الصفحة المسارات نفسها الموجودة في GitHub Pages وملف ZIP.
