# Car Rental Website — حل الوظيفة

## محتويات المشروع

| الملف | الوظيفة |
|---|---|
| `home.html` | الصفحة الرئيسية، أسماء المجموعة، رابط النشر والملاحظات |
| `AboutUs.html` | معلومات مكتب التأجير والتواصل والفروع وأوقات الدوام |
| `Cars.html` | جدول من 6 سيارات، اختيار متعدد، تفاصيل jQuery، ونموذج الحجز |
| `style.css` | ملف التنسيق الموحد والمتجاوب |
| `myFunctions.js` | ملف JavaScript الوحيد للتحقق والحساب والتفاعل |
| `AI_Feature_Report.html` | تقرير مختصر عن ميزة «مستشار السيارة الذكي» |

## التشغيل

افتح `home.html` في المتصفح. تحتاج صفحة `Cars.html` إلى اتصال بالإنترنت لتحميل مكتبة jQuery من CDN.

## خطوات ما قبل التسليم

1. استبدل الحقول `[يُضاف الرقم]` في `home.html` بالأسماء والأرقام الجامعية الحقيقية لجميع أفراد المجموعة.
2. استبدل رابط `https://example.com/car-rental` برابط الاستضافة المجاني الفعلي بعد نشر الموقع.
3. أعد تسمية الملف المضغوط باسم أرقام الطلاب المشاركين وفق تعليمات المدرّس، ثم ارفعه إلى Moodle.

## الوظائف المنفذة

يستخدم المشروع XHTML 1.0 Strict مع إغلاق الوسوم الفارغة ووضع قيم السمات بين علامتي اقتباس. ويستخدم النموذج `fieldset` و`label` وأنواع إدخال مناسبة مثل `date` و`tel` و`email`.

يتحقق JavaScript من الاسم العربي، والرقم الوطني المؤلف من 11 خانة والذي يبدأ برمز محافظة من 01 إلى 14، وصحة التواريخ، ورقم الهاتف السوري، والبريد الإلكتروني. كما يمنع تاريخ نهاية يساوي أو يسبق تاريخ البداية، ويحسب مدة التأجير ومبلغ كل سيارة والمجموع النهائي مع خصم 10% عند تجاوز 7 أيام.

تظهر تفاصيل عدة سيارات أو تختفي باستخدام jQuery و`slideToggle` دون إعادة تحميل الصفحة، ثم تظهر نتيجة الحجز والسيارات المختارة والمدة والمبلغ النهائي.
