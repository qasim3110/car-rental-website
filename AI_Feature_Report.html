مستشار السيارة الذكي

تقرير مختصر عن ميزة واحدة مقترحة لتحسين تجربة الزبون.

1. اسم الـ Feature

مستشار السيارة الذكي (Smart Car Advisor)

2. الهدف منها

مساعدة الزبون على اختيار السيارة الأنسب بسرعة بدلًا من مقارنة جميع السيارات يدويًا. تعتمد الميزة على تحليل احتياجاته مثل عدد الركاب، الميزانية اليومية، نوع الاستخدام، ناقل الحركة، ومدة الرحلة، ثم تعرض السيارات الأكثر ملاءمة مع تفسير مختصر لسبب التوصية.

3. المستخدم المستهدف

الزبون أو الزائر الذي لا يعرف أي سيارة تناسب احتياجاته، مع إمكانية استفادة موظف الحجز من التوصية عند التواصل مع الزبائن.

4. وصف طريقة عمل الـ Feature

  1. يفتح الزائر نافذة المستشار ويجيب عن أسئلة قصيرة: عدد الركاب، الميزانية، المدينة/الطريق، تفضيل الوقود، ووجود أمتعة.
  2. تحول الإجابات إلى متجه خصائص، ثم تقارن بخواص السيارات المتاحة وقواعد الملاءمة.
  3. يمكن استخدام نموذج تعلم آلي بسيط للتصنيف أو نظام توصية يعتمد على التشابه، مع تزويده ببيانات الحجوزات السابقة بعد إزالة البيانات الشخصية.
  4. تحصل كل سيارة على درجة ملاءمة، وتظهر أفضل ثلاث نتائج مع السعر اليومي، سبب التوصية، وزر «اختيار» ينقل السيارة إلى جدول الحجز.
  5. يستطيع الزبون تعديل إجاباته، وتُعاد التوصيات فورًا دون إعادة تحميل الصفحة.

5. خطوات التنفيذ

  1. تجهيز البيانات: إنشاء سجل موحد لكل سيارة يتضمن السعر، المقاعد، الوقود، ناقل الحركة، سنة الصنع، وسعة الأمتعة، مع سجلات حجوزات مجهّلة.
  2. تصميم الواجهة: بناء نموذج أسئلة بسيط ومتجاوب مع رسائل واضحة، وإتاحة خيار «لا يهمني» حتى لا تكون التوصية منحازة.
  3. بناء محرك التوصية: البدء بقواعد مرجّحة قابلة للتفسير، ثم تدريب نموذج تصنيف/ترتيب عند توفر بيانات كافية. مثال: زيادة وزن المقاعد إذا كان عدد الركاب كبيرًا، واستبعاد السيارات التي تتجاوز الميزانية.
  4. الربط بالموقع: إنشاء API يستقبل الإجابات ويعيد السيارات المرتبة، ثم ربطه بواجهة JavaScript مع عرض حالة التحميل والأخطاء.
  5. الاختبار والقياس: اختبار حالات مختلفة، قياس نسبة النقر على التوصيات والحجوزات الناتجة، ومراجعة التوصيات دوريًا من موظف المكتب.
  6. الخصوصية والأمان: عدم تخزين الرقم الوطني أو بيانات الاتصال لغرض التدريب، وتسجيل الموافقة عند استخدام بيانات الحجز المجهّلة.

النتيجة المتوقعة: تقليل وقت الاختيار، رفع رضا الزبون، وزيادة احتمال إتمام الحجز، مع إبقاء القرار النهائي بيد الزبون وعدم تقديم توصية مضللة أو إلزامية.
